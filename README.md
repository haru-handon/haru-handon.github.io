# 하루 한돈

> 매일 한 돈씩 쌓이는 행운의 골드바

"행복하세요, 돈 많이 버세요"라는 마음을 담은 행운 앱입니다. 하루 한 번 금고를 열면 금 1돈이 골드바에 더해지고, 오늘의 재물운 덕담을 받습니다.

- 개발: 오상플레이
- 패키지명 / 번들 ID: `com.ohsang.util.haruhandon`
- 소개 페이지: https://haru-handon.github.io (예정: haru-handon.ohsangplay.com)
- 광고: 첫 출시는 광고 없음 (추후 "출석 복구" 보상형 광고만 검토)

## 앱 규칙

| 항목 | 규칙 |
| --- | --- |
| 출석 | 하루 한 번 금고를 연 날에만 금 1돈(3.75g) 추가. 날짜 기준은 기기 현지 시간 자정 |
| 안 연 날 | 무게는 그대로, 연속 출석만 끊김 |
| 단위 | 10돈 = 1냥. 표기는 `1냥 3돈`, 그램은 `돈 × 3.75g` |
| 1냥 달성 | 10돈마다 축하 화면 (빛줄기, 떨어지는 골드바, 팡파레) |
| 금고 단계 | 0돈 철제 금고 → 1냥 황동 금고 → 3냥 금빛 금고 → 10냥 황금 대금고 |
| 덕담 | 날짜마다 정해진 문구 하나 (`Fortunes.kt`) |
| 알림 | 매일 아침 8시, 오늘 아직 금고를 안 열었을 때만 |
| 위젯 | 2×2 (골드바 + 무게), 4×2 (골드바 + 무게·그램·덕담) |
| 기록 보관 | 기기 안에만 저장. Android 자동 백업으로 재설치·기기 변경 시 복원 |

## 화면 흐름

1. 금고 화면: 문을 누르면 다이얼이 돌아가고(틱 소리·진동) 문이 열림
2. 골드바가 앞으로 나오며 커짐. 새 출석이면 번쩍임 + `+1돈` + 무게 카운트업
3. 골드바를 누르면 빛줄기·반짝이·띵 소리, 잡고 옆으로 돌리면 뒷면(福, 행복하세요 / 돈 많이 버세요)
4. "금고 보관"을 누르면 골드바가 들어가고 문이 닫힘

## Android 빌드

Android Studio(최신 안정판)에서 `android/` 폴더를 엽니다.

```
cd android
./gradlew assembleDebug
```

- Gradle 8.13 래퍼가 들어 있어 처음 동기화할 때 Gradle을 자동으로 받습니다.
- 알림 아이콘·앱 아이콘·골드바 그림은 모두 벡터(`res/drawable`)이고, 효과음은 `res/raw`의 합성 wav입니다.
- 라이브러리 버전은 `gradle/libs.versions.toml`에 모여 있습니다. Android Studio가 업그레이드를 제안하면 따라도 됩니다.
- 디버그 빌드에는 화면 아래에 테스트용 버튼(다음 날, 다음 냥 직전, 초기화)이 나옵니다. 릴리스 빌드에는 나오지 않습니다.
